# BCS স্টাডি ক্লক — হোস্টিং গাইড

এই ফোল্ডারে ৪টা ফাইল আছে: `index.html`, `manifest.json`, `sw.js`, `icon.png`।
এগুলো একসাথে (একই ফোল্ডারে) যেকোনো ফ্রি স্ট্যাটিক হোস্টিং-এ আপলোড করলেই সাইট লাইভ হয়ে যাবে। কোনো সার্ভার, ডাটাবেস, বা বিল্ড কমান্ড লাগবে না।

## সবচেয়ে সহজ উপায়: Netlify Drop (২ মিনিট)
1. ব্রাউজারে যাও: https://app.netlify.com/drop
2. এই পুরো ফোল্ডারটা (৪টা ফাইলসহ) সরাসরি ওই পেজে ড্র্যাগ করে ছেড়ে দাও
3. সাথে সাথে একটা লিংক পাবে (যেমন `https://xxxx.netlify.app`) — এটাই তোমার লাইভ সাইট
4. ফ্রি অ্যাকাউন্ট খুললে (কার্ড লাগে না) পরে সাইটের নাম বদলাতে পারবে, কাস্টম ডোমেইনও যোগ করা যাবে

## বিকল্প: Vercel
1. https://vercel.com এ ফ্রি অ্যাকাউন্ট খোলো
2. "Add New Project" → ফোল্ডার আপলোড বা GitHub রিপোতে পুশ করে কানেক্ট করো
3. Deploy চাপলেই লিংক পাবে

## বিকল্প: GitHub Pages (যদি GitHub ব্যবহার করো)
1. একটা নতুন রিপোজিটরি বানাও
2. এই ৪টা ফাইল আপলোড করো
3. Settings → Pages → Branch: main, Folder: / (root) সিলেক্ট করে Save করো
4. কিছুক্ষণ পর `https://<username>.github.io/<repo-name>` এ লাইভ হবে

## নিজের ডোমেইন যোগ করা
Netlify বা Vercel দুটোতেই "Domain settings" এ গিয়ে তোমার কেনা ডোমেইন (যেমন Namecheap/GoDaddy থেকে কেনা) যোগ করার অপশন আছে — সেখানে তারা কিছু DNS রেকর্ড (A/CNAME) দেবে, সেগুলো তোমার ডোমেইন প্রোভাইডারের DNS সেটিংসে বসিয়ে দিলে ডোমেইনটা তোমার সাইটে পয়েন্ট করবে। DNS আপডেট হতে কয়েক ঘণ্টা লাগতে পারে।

## ফোনে হোমস্ক্রিনে "ইনস্টল" করা
সাইট লাইভ হওয়ার পর:
- **Android (Chrome):** সাইট খুলে উপরে ডানে ⋮ মেনু → "Add to Home screen" / "Install app"
- **iPhone (Safari):** সাইট খুলে নিচের Share আইকন → "Add to Home Screen"

এরপর হোমস্ক্রিনে একটা আইকন থাকবে, ট্যাপ করলে ফুল-স্ক্রিনে অ্যাপের মতোই খুলবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- নোট, পিডিএফ, রিভিশন ডেটা **শুধু ব্রাউজারে** (localStorage) সেভ হয় — অন্য ডিভাইস থেকে খুললে সেই ডেটা দেখা যাবে না, আর ব্রাউজার ডেটা/ক্যাশ ক্লিয়ার করলে হারিয়ে যাবে
- পিডিএফ ফাইল ৪MB এর বেশি হলে সেভ হবে না (ব্রাউজার স্টোরেজের সীমার কারণে)
- অ্যালার্ম শব্দ শুধু তখনই বাজবে যখন ট্যাব/অ্যাপ খোলা আছে — ফোনের ব্যাকগ্রাউন্ডে গেলে বাজবে না। ব্যাকগ্রাউন্ডেও নির্ভরযোগ্য এলার্মের জন্য ফোনের নিজস্ব Clock অ্যাপের এলার্মই ব্যবহার করা ভালো

## অফলাইনে চালানো
এখন সাইটে অফলাইন সাপোর্ট আছে (`sw.js`)। প্রথমবার নেট থাকা অবস্থায় সাইট একবার খুললেই ফাইলগুলো ব্রাউজারে cache হয়ে যায় — এরপর নেট না থাকলেও পেজটা খুলবে, আর localStorage-এর নোট/পিডিএফও কাজ করবে।

**পরবর্তীতে `index.html` বা অন্য ফাইল আপডেট করলে**, `sw.js` ফাইলের ভেতরে থাকা এই লাইনটা বদলাতে ভুলো না:
```
const CACHE_NAME = 'bcs-study-clock-v2';
```
প্রতিবার আপডেট দেওয়ার সময় `v2` কে `v3`, `v4`... এভাবে বাড়িয়ে দিতে হবে। না বাড়ালে ব্রাউজার পুরনো cache করা ভার্সনই দেখাতে থাকবে, নতুন আপডেট দেখাবে না।
